# dsh-turn-scratch

一款专门用于清理 dsh 每轮产生的多余临时文件的插件。

## 介绍

是不是还在因为dsh忙完工作后，工作区里到处都是它产生的临时文件而苦恼？

您是否经常感觉到自己不知道这些文件的作用？删除时又怕这些文件会影响你的电脑？

或者是自己还要在每次对话时做出删除临时文件这种重复性动作？

不用担心，dsh-turn-scratch 这款插件能帮你的忙。

## 安装

dsh plugin --profile desktop add git+https://github.com/popujiang/dsh-turn-scratch.git

## “小而美”

插件体积很小，而且很多操作无感完成，让你放心。

当然，真的是小而美：

很多操作无感完成，默认无需配置，开箱直用！

为什么？因为它是全自动的。

不过想调的话，配置项都在。

*但是你怕dsh误删？*

早就想好了这一点！

## 特色

**它并不是直接删文件**

每轮结束，临时文件全都会先被挪进一个回收文件夹（不是你电脑里的回收站），再逐个判断：

能确定的，代码直接决定去留。

拿不准的，才交给 agent 建议。

真正的删除，只在你手动清空时发生。

在你还什么都没察觉的时候，分类已经发生，连工作区的界面也跟着清爽了起来。

*所以最坏的情况其实是文件被隔离开来，而不是被误删*

## 包含的工具及其作用

| 工具 | 作用 |
|---|---|
| scratch_status | 看现在扣着什么、已还原什么 |
| scratch_restore | 手动把一个文件捞回工作区 |
| scratch_purge | 清空隔离区（真删） |
| scratch_mark | 标记某个文件不要动 |

## 安全

默认只隔离，不删除

拿不准的文件还是会留着，不会误杀

agent 只能建议还原，不能替你删除，最后文件的生杀大权在你手里

插件经过多轮测试，无误删记录。最坏的情况是文件被隔离，随时可还原，请食客放心食用。
